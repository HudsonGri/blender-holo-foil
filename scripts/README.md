# Scripts

Everything in `holo_foil.blend` is generated by these scripts; nothing is hand-edited. Outputs that are not
committed go to `build/`. Needs Blender 5.2+ (`blender` on your PATH) and, for the tests and the gallery, a Python 3
with numpy and Pillow.

## Rebuild

```sh
blender -b --factory-startup --python scripts/build_holo_foil.py          # -> holo_foil.blend
blender -b --factory-startup --python scripts/build_shader.py             # the BSDF alone -> build/diffraction_grating.blend
blender -b --factory-startup -t 6 --python scripts/tests/smoke_test.py    # append + tiny CPU render, prints PASS
scripts/render_gallery.sh                                                 # -> docs/images/pattern_gallery.jpg + asset previews
```

| file | builds |
|---|---|
| `build_shader.py`, `spectral.py` | the Diffraction Grating BSDF, its demo material, the DG Foil Denoise compositor group and the demo scene |
| `build_patterns.py` | the Holo Pattern groups, Holo Card Shader and the Holo Card material (procedural demo art) |
| `build_holo_foil.py` | runs both, marks the assets, saves `holo_foil.blend` |
| `render_gallery.py`, `render_gallery.sh`, `compose_gallery.py` | the pattern gallery and the asset previews (re-run `build_holo_foil.py` afterwards to embed them) |

## Tests

Each test checks the shader against physics: a white furnace, the grating equation for the exact scene geometry, or
real disc track pitches (CD 1.6 µm, DVD 0.74 µm, Blu-ray 0.32 µm).

```sh
python3 scripts/tests/run.py --list                       # the tests and their settings
python3 scripts/tests/run.py --variants ours              # all tests, our shader, quick CPU settings
python3 scripts/tests/run.py --tests laser --variants ours # about 2-5 min on a CPU; reads back d ≈ 1.61 µm
python3 scripts/tests/run.py --quality full --device GPU  # the published sample counts
```

| test | checks |
|---|---|
| `white_room` | a lossless foil in a uniform white world must read 1.0 (mean per object, no denoiser) |
| `laser`, `laser_discs` | white beam on a CD / DVD / Blu-ray; measure the colour peaks on a screen and solve `d = mλ / sin θ` |
| `discs` | CD, DVD and Blu-ray under one small lamp vs the grating equation evaluated for that exact lamp and camera |
| `grid49`, `banding` | one light, 49 copies (2D lattice); one lamp up close (continuous spectrum vs separate copies) |
| `rainbow_order`, `order_check` | colour order next to the mirror highlight, textbook vs Balanced's lobe law |
| `grazing` | white-furnace probe at 60–85° views |

Results go to `build/tests/` (`.png`, linear `.npz`, and `.json` with every setting and timing, plus the
measurement JSON).

**Comparing with "Balanced".** Secrop's shader (CC BY 4.0) is not included. Download the .blend from
[Blender Guru's post](https://www.blenderguru.com/posts/2026/8/13/why-you-cant-render-pokemon-cards-in-blender)
("Download the .Blend File"), unzip it, and run:

```sh
BALANCED_BLEND=/path/to/BlenderGuru_DiffractionGrating_3Solutions.blend python3 scripts/tests/run.py
```

Both shaders then get identical scenes, lights, cameras, samples, seed and denoiser; only the material changes, and
Balanced's settings are mapped 1:1 (`tests/lib/common.py`). `tests/measure_gains.py` re-measures the brightness
match used in the look comparisons.
